# Lunari 3.0 🌙🌸

Site estático HTML/CSS/JavaScript para GitHub Pages.

## Publicação
Copie **o conteúdo desta pasta** para a raiz do repositório `lunari_site` e habilite GitHub Pages na branch principal. Abra `index.html` localmente para testar.

## Incluído
16 fotografias originais selecionadas, carrossel, ampliação de fotos, Spotify incorporado, céu de estrelas, jardim com quatro estações, árvore dos desejos, mensagens, linha do tempo, cápsula com senha simbólica 261026, livro de lembranças e cartas surpresa.

## Personalização
Edite `js/main.js` (objeto CONFIG) para textos e datas; edite `index.html` para carta e conteúdo. As datas genéricas da linha do tempo precisam ser preenchidas com fatos confirmados.

## Privacidade
O GitHub Pages é público. A senha da cápsula não protege arquivos nem cartas; `localStorage` não sincroniza dispositivos e pode ser apagado. Confirme autorização antes de publicar fotos. O Spotify exige interação do visitante e está sujeito às regras de reprodução do serviço.

## Verificações
Confira o site no navegador, especialmente em celular, antes de publicar.
